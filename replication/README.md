### Empirical Application

The `TwoSampleIV` package includes an empirical application using data from:

Marshall, John (2019). *The Anti-Democrat Diploma: How High School Education Decreases Support for the Democratic Party*. American Journal of Political Science, 63(1), 67–83.

**Original replication data:** [Harvard Dataverse, DOI: 10.7910/DVN/GPRVC6](https://doi.org/10.7910/DVN/GPRVC6).

The application demonstrates the use of `tsiv()` and `tsiv_sum()` to estimate the effect of schooling on political preferences using two-sample instrumental variables methods.

The Stata datasets are taken directly from the original replication archive and used without further modification.

The application provides examples of one-step, two-step efficient IV, and continuously updated estimation, together with weak-instrument diagnostics and Anderson–Rubin confidence sets.
